# Автоматизированные тесты. Lesson 10

## Описание проекта

Проект содержит автоматизированные UI-тесты с использованием Selenium WebDriver, Pytest и PageObject.

В проекте реализованы:

- тест калькулятора;
- тест оформления заказа в интернет-магазине;
- Allure-отчёты для результатов тестирования.

## Запуск тестов

Для запуска тестов выполнить команду:

```bash
python -m pytest lesson_10
```

## Формирование Allure отчёта

Для формирования результатов Allure выполнить команду:

```bash
python -m pytest lesson_10 --alluredir=allure-results
```

## Просмотр Allure отчёта

Для просмотра отчёта выполнить команду:

```bash
allure serve allure-results
```

## Проверка стиля кода

Для проверки соответствия PEP8 выполнить команду:

```bash
flake8 lesson_10
```
